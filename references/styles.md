# Six built-in scientific styles

## S1 Compact Modular Architecture

ID: `s1-compact-modular`

Use a dense top-level architecture with compact modules and lower detail panels. Use dashed macro regions, small tensor/vector glyphs, and clear left-to-right flow. Prefer for multimodal systems, attention architectures, time-series models, and methods that need overview plus selected implementation details.

## S2 Multi-panel Decomposition

ID: `s2-multi-panel`

Use an overall workflow panel and labelled detail panels such as `(a)`, `(b)`, `(c)`, and `(d)`. Use consistent rounded panel borders and reference mappings. Prefer for methods whose innovation is distributed across several internal modules, reconstructions, mask processes, or cross-modal operations.

## S3 Dense Engineering Architecture

ID: `s3-dense-engineering`

Use compact depth columns, stage-like progression, explicit dimensions, small gaps, and strong engineering density. Prefer for time/frequency pipelines, encoder-decoder networks, multi-head outputs, multi-scale processing, or architectures where implementation detail matters.

## S4 Macro Partition

ID: `s4-macro-partition`

Use a small number of large containers with generous whitespace. Place modules in clear vertical or grid order inside each macro stage. Prefer for conceptual frameworks, dual-branch methods, reasoning versus forecasting systems, and figures emphasizing the big idea rather than every tensor operation.

## S5 Rigorous Relation Graph

ID: `s5-rigorous-graph`

Use strong scholarly typography, dark primary arrows, grey dashed partitions, structured graph/vector/probability glyphs, and a dedicated output region. Prefer for relation extraction, event extraction, graph neural networks, evidence extraction, classification, and calibrated probability pipelines.

## S6 PaperBanana Soft Scientific

ID: `s6-paperbanana-soft`

Use soft scientific pastels, rounded process modules, light semantic containers, orthogonal arrows, consistent grids, and intentional whitespace. Keep warm colors for training or optimization, cool colors for data and representation, and teal for results. Use as the general default.

## Shared requirement

All styles render one semantic Figure IR. Style changes may alter layout, grouping, density, shape treatment, typography hierarchy, and color mapping. They must not alter scientific meaning.
