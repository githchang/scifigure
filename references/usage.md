# Installation and command reference

## Use through Codex

SciFigure accepts free-form requests in the current conversation. The user does not need to create `method.md`, fill a prompt form, or supply Figure IR.

Example:

```text
使用 $scifigure，把下面的科研内容和绘图要求转化为六种风格的 PNG 预览：

这里可以输入任意自然语言、论文内容、公式、源码说明、文件引用、草图说明或排版要求。
```

SciFigure internally creates `figure_ir.json`, validates it, and invokes the bundled renderer.

## Direct use from the skill folder

The CLI is an internal deterministic renderer. It consumes Figure IR generated by Codex or prepared by a developer.

```bash
python -m pip install -r requirements.txt
python scripts/scifigure.py preview --ir examples/demo_ir.json --output run/previews
```

`init-ir` copies a developer example for renderer testing. It is not part of the required user workflow:

```bash
python scripts/scifigure.py init-ir --output figure_ir.json
```

## Install the CLI locally

```bash
python -m pip install -e .
scifigure preview --ir examples/demo_ir.json --output run/previews
```

## Commands

Validate internal semantic IR:

```bash
scifigure validate-ir --ir figure_ir.json
```

Generate six PNG previews and a PNG contact sheet:

```bash
scifigure preview --ir figure_ir.json --output run/previews
```

Generate one revised preview:

```bash
scifigure render \
  --ir figure_ir.json \
  --style s2-multi-panel \
  --output run/selected \
  --name selected_preview_v2
```

Generate final files after approval:

```bash
scifigure finalize \
  --ir figure_ir.json \
  --style s2-multi-panel \
  --output run/finalized
```

Final deliverables are stored in:

```text
run/finalized/final/figure_final.png
run/finalized/final/figure_final.svg
run/finalized/final/figure_final.vsdx
```
